Política de Privacidade — Organizador PlayKaraoke

Última atualização: 26 de outubro de 2026.

O Organizador PlayKaraoke é uma ferramenta interna, executada no computador do dono do canal PlayKaraoke, para publicar no YouTube os vídeos produzidos pelo próprio canal.

Dados acessados

Com a autorização do dono do canal (Google OAuth), a ferramenta usa a YouTube Data API para: enviar vídeos, definir título, descrição, tags, idioma e miniatura, criar playlists e adicionar vídeos a elas, e ler a lista de vídeos e playlists do próprio canal para evitar envios duplicados. Nenhum dado de espectadores ou de outros usuários é acessado.

Armazenamento

A autorização e o registro de progresso ficam apenas no computador do dono do canal. Nada é enviado a servidores próprios ou de terceiros, além das chamadas à própria API do YouTube.

Compartilhamento

Nenhum dado é vendido, compartilhado ou usado para publicidade.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. A ferramenta usa os Serviços da API do YouTube; veja os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Privacy Policy — Organizador PlayKaraoke

Organizador PlayKaraoke is an internal tool, run on the PlayKaraoke channel owner's computer, to publish the channel's own videos on YouTube.

Data accessed: with the channel owner's OAuth consent, the tool uses the YouTube Data API to upload videos, set title, description, tags, language and thumbnail, create playlists and add videos to them, and read the channel's own videos and playlists to avoid duplicate uploads. No viewer or third-party user data is accessed.

Storage: the authorization token and progress log are stored only on the channel owner's computer. No data is sent to any server other than the YouTube API itself.

Sharing: no data is sold, shared or used for advertising.

Revocation: access can be revoked at any time at myaccount.google.com/permissions. This tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
